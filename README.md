# Workout Manager

Aplicação fullstack de gestão de treinos personalizados com inteligência artificial.

## Sobre

O Workout Manager é uma plataforma que utiliza IA para criar e gerenciar planos de treino personalizados. O usuário faz login com Google, conversa com um personal trainer virtual que coleta seus dados físicos e monta um plano de treino completo baseado nos seus objetivos.

## Tecnologias

**Frontend**
- Next.js 16
- TypeScript
- Tailwind CSS v4
- Better Auth

**Backend**
- Fastify
- TypeScript
- Prisma + PostgreSQL
- Better Auth
- Groq (LLaMA)
- Docker
